# Final Clustro paper figures

This directory contains the publication-figure generator for the Clustro methods paper.

It reads the reviewer-driven analysis outputs already produced by this repository. It does **not** refit clustering models.

## Required inputs

Run the methods-revision and reporting steps first so that this directory exists:

```text
results/methods_revision_reporting/
```

The figure generator expects the candidate audit, null-reference, sensitivity, cluster-size, and representation-sensitivity CSV files written there by `generate_methods_revision_reporting.py`.

Figure 4 also uses the data-faithful phenotype heatmap generated by that reporting pipeline. By default the script searches for:

```text
results/methods_revision_reporting/figure3_phenotype_profiles_revised.png
```

You can override it with `--phenotype-image`.

## Generate all figures

From the repository root:

```bash
source .venv/bin/activate
python paper_figures/make_figures.py --pdf
```

Outputs are written to:

```text
results/final_paper_figures/
```

This creates 600-dpi PNG files and vector PDFs.

## Useful options

```bash
# only Figures 2 and 5
python paper_figures/make_figures.py --only 2 5 --pdf

# custom reporting directory
python paper_figures/make_figures.py \
  --reporting-dir results/methods_revision_reporting \
  --outdir results/final_paper_figures \
  --pdf

# explicit phenotype heatmap
python paper_figures/make_figures.py \
  --phenotype-image results/methods_revision_reporting/figure3_phenotype_profiles_revised.png \
  --pdf
```

## Figure set

1. Clustro workflow and decision logic
2. Model-selection landscape and selected solutions
3. Null-reference benchmarking
4. Cluster-profile interpretation
5. Specification robustness

The figures are reporting-only. Numerical panels are generated from the machine-readable analysis outputs. Figure 4 embeds the final data-faithful phenotype heatmap produced by the existing reporting pipeline.


## Compact journal layout

The current generator uses the compact journal layout: reduced canvas height, tighter panel spacing, minimal export padding, and automatic white-border cropping for the phenotype heatmap. This version replaces the earlier spacious presentation-style layout.


## Better-aligned manuscript layout

The current generator uses the tighter manuscript layout reviewed in September 2026. It keeps the improved alignment and compact panel geometry while reading the **real reviewer-driven analysis outputs** from `results/methods_revision_reporting/`.

Important implementation details:

- Figure 3 uses the actual 100 Gaussian-copula null replicate silhouettes from `results/methods_revision/` when those CSV files are available. It does not synthesize a null distribution.
- Figure 4 keeps the real phenotype heatmap produced by the analysis/reporting pipeline. It does not substitute the mock-up heatmap values.
- Figures 2 and 5 read the final candidate-audit, full-refit stability, balanced-block, representation, and WBC-redundancy outputs.
- Figure 1 reports the final workflow, including 80% subsampling with full preprocessing refit and 50 repeats.

Generate the complete set with:

```bash
python paper_figures/make_figures.py \
  --outdir results/final_paper_figures_v3 \
  --pdf
```

The PNG and PDF files can be opened or downloaded directly from `results/final_paper_figures_v3/`; no local server is required.
